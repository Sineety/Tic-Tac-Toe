# Tic-Tac-Toe
Учебный проект разработанный в рамках предмета "Программная инженерия".

## Режимы игры
а) игроку с компьютером;  
б) двум игрокам.

## Ход компьютера
Если в качестве игрока выступает компьютер, программа делает первый ход.  
Делая очередной ход, программа анализирует ситуацию, рассчитывая возможные ходы противника вперед на 1 — 2 хода, и в результате проведенного анализа поступает оптимальным образом.
