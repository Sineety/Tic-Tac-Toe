# Крестики-нолики
Учебный проект разработанный в рамках предмета "Программная инженерия".

## О проекте
- Игра представляет собой «крестики-нолики» на бесконечном поле.
- Реализованы два режима:
  - игрок против компьютера;
  - два игрока.
- Если в качестве игрока выступает компьютер:
  - программа делает первый ход;
  - делая очередной ход, программа анализирует ситуацию, рассчитывая возможные ходы противника вперед на 1–2 хода;
  - в результате проведенного анализа программа поступает оптимальным образом.

## Цели проекта
- Реализовать игру «крестики-нолики» на бесконечном поле.
- Реализовать режим игры игрока с компьютером.
- Реализовать режим игры двух игроков.
- Реализовать алгоритм компьютера: первый ход, анализ ситуации, расчет возможных ходов противника на 1–2 хода вперед, выбор оптимального хода.

## Структура проекта
- Будет разрабатываться в течении семестра
